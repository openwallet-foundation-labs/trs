# Tech Report

This section collects **technical reports** on the Trust Resolver System —
design rationale, protocol analyses, interoperability findings, and evaluation
results that go beyond the day-to-day developer documentation.

Where the [Docs](/) describe *how TRS works and how to contribute*, tech reports
explain *why* it is built the way it is and record what we learned along the way.

## Reports

Reports are listed in the sidebar. Each report is a self-contained document with
its own context, findings, and references.

## Writing a report

Add a Markdown file under `website/tech-report/` and register it in
`website/sidebarsTechReport.js`. Start each report with front matter:

```md
---
title: <Report title>
description: <One-line summary>
---
```
